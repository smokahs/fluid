

# Fluidify
**Unify multiple different mod's varying fluid units!** 

Forge 1.20.1. 

See the [changelog](https://github.com/smokahs/fluidify/blob/master/CHANGELOG.md) for all details!

## Use this!

`/fluidify dump` prints the unit, the number mods being changed, and how many fluids were cached. The full log can found in latest.log
